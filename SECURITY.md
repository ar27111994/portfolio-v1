# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Do not open a public issue.** Instead, send details to:

- **Email:** [admin@ar27111994.dev](mailto:admin@ar27111994.dev)

Include:

- A description of the vulnerability
- Steps to reproduce
- Affected versions
- Any potential mitigations you've identified

You will receive an acknowledgment within 48 hours. I aim to resolve critical
issues within 7 days and will keep you updated on progress.

## Scope

This policy covers the `portfolio-v1` codebase and the deployed site at
`ar27111994.dev`, including:

- The Astro static site and its build pipeline
- Vercel serverless functions (`api/`)
- Any client-side JavaScript served from the domain

Out of scope: third-party services (Vercel, GitHub, Upwork), and the
`products.ar27111994.dev` subdomain.

## Responsible Disclosure

I appreciate coordinated disclosure. Once a fix is deployed, you are welcome
to publish your findings. Credit will be given in release notes unless you
request anonymity.
